## If Something Doesn't Look Right:

### Images Not Loading?
- Check your internet connection (images from Unsplash)
- Hard refresh the page: `Cmd + Shift + R` (Mac) or `Ctrl + Shift + R` (Windows)

### Styles Look Weird?
- Clear browser cache
- Check browser console for errors (F12)
- Make sure server is running at http://localhost:3001

### Layout Issues?
- Try different browser (Chrome, Safari, Firefox)
- Check viewport width (works best at 1024px+ for desktop view)
